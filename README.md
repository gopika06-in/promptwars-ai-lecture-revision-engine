# PromptWars '26 
# 📚 AI Lecture Revision Engine
> **PromptWars Community 2026 Submission** | *Option A: AI-Powered Student Workspace*

An intent-driven, AI-powered study tool that transforms raw lecture materials into structured revision guides, terminology cheat sheets, and interactive practice quizzes in seconds.

---

## 🚀 Features
- **Multi-Format Ingestion:** Supports `.pdf`, `.docx`, and `.txt` files, or raw text input.
- **Course Personalization:** Tailors output tone and focus for Bioengineering, Computer Science, Business, and General subjects.
- **High-Yield Output:** 
  - Executive summary & key exam concepts.
  - Terminology and formula cheat sheets.
  - 5-question multiple choice practice quiz with interactive self-testing.
- **One-Click Export:** Download the entire study kit as a structured `.md` file.

---

## 🛠️ Tech Stack
- **Frontend & UI:** Python, Streamlit
- **AI Model:** Google Gemini API (`gemini-2.5-flash`) via `google-genai` SDK
- **File Parsing:** `pypdf`, `python-docx`
